# Contributing

Pull requests are welcome. The maintainer decides what merges.

- For a change of behaviour, open an issue first.
- Fork the repository, make a branch and open a pull request to `main`.
- Run `make check` before you push. [docs/development.md](docs/development.md) has the commands.
- Write the title as `<type>(<scope>): <subject>`, for example `fix(face): centre the count`. The pull request
  merges as one squashed commit with this title.
- You do not need signed commits. GitHub signs the squashed commit.
- The checks of an outside pull request start after the maintainer approves the run.
- For a security problem, see [SECURITY.md](SECURITY.md).
